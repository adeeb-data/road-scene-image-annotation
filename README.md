# Road Scene Image Annotation Using CVAT

## Project Overview

This project focuses on annotating road scene images using CVAT (Computer Vision Annotation Tool).

A total of 9 road traffic images were manually annotated to identify and classify different objects and road-related elements.

## Tools Used
- CVAT – Image Annotation
- COCO 1.0 – Dataset Export
- CVAT XML – Annotation Backup
- GitHub – Dataset Version Control

## Annotation Classes

The project includes road traffic objects and environmental elements such as:

- Car
- Bus
- Truck
- Person / Pedestrian
- Traffic Light
- Road and other road-related areas

## Annotation Details

- Manually annotated 9 road scene images.
- Assigned separate labels and colours to distinguish annotation classes.
- Annotated traffic objects and road-related regions.
- Used appropriate annotation shapes based on the object or region.
- Exported annotations in COCO and CVAT formats.

## Dataset Information

- Total Images: 9
- Annotation Tool: CVAT
- Dataset Format: COCO 1.0
- Backup Format: CVAT for images 1.1
- Project Type: Road Scene Image Annotation

## Purpose

The purpose of this project is to gain practical experience in image annotation and dataset preparation for computer vision and object detection applications.
